# {项目名} — 视觉设计规范

> **负责人**: PM / 设计师
> **用途**: 定义产品的视觉风格和设计体系。高UX要求的项目需要完整的设计系统；对美术要求不高的项目应明确选用UI框架并说明定制范围。
> **与原型/图表的关系**: 页面布局和组件结构由 `sprints/*/prototypes/prototype.html`（可交互原型）承载，系统层图表（用例/ER/架构）见 `uml-pack.md`；本文档只定义视觉层（颜色、字体、间距、图标、品牌）。
> **必填规则**: 即使项目无前端界面（纯后端/脚本/CLI），也**必须保留此文件**。无实质内容时写一行占位说明为什么不需要，不可遗漏或删除。
